## 구현 범위

제공 JSON 한 번 반영, 실제 IndexedDB 저장·재접속, 일·월 조회, 메뉴·채널별 수익성, 판매 추가·수정·삭제, 저장 전 계산·재료 사용량 미리보기, 실제 수수료 입력, 하루 마감·재마감, 검색·필터·페이지 이동, 입력·저장 오류와 여러 탭 저장 충돌 처리를 구현했다.

EPIC 2·3의 비용 입력·손익·백업·재고 등록·최소 기준 설정·복원 화면은 구현하지 않았다. 제공된 비용·재고 등 원기록은 저장 상태에 보존하고, EPIC 1의 판매 재료 사용 계산과 실측 보호 로직을 검사했다. 가짜 완료 버튼이나 시안의 고정 수수료·원가를 실제 동작으로 쓰지 않았다.

### 검사 중 발견·조치

- 메뉴·채널 합계가 이전 그룹의 합계를 이어받는 오류를 발견해 각 그룹을 0부터 계산하도록 수정했다. 금액 합계와 실제 화면 검사가 통과했다.
- 검사 기대값의 포장 원가 추정값을 실제 가격이력 166.4원으로 바로잡았다.
- 12개 포장 판매의 정확한 공헌이익 41,404.8원은 화면에 41,405원으로 표시된다. 검사 기대값도 문서의 반올림 규칙에 맞췄다.
- 초기 로딩 중 마감 버튼 실행과 저장 중 입력 변경을 차단했다. 최종 브라우저 검사를 다시 실행해 통과했다.
- 여러 탭 저장 충돌 후에도 입력창 안에서 최신 자료를 읽을 수 있도록 보완했다. 비동기 읽기 완료 후 판정하도록 검사 대기 조건도 보완했다.
- 제한된 실행 환경에서 브라우저 연결이 거부되어, 승인된 로컬 실행 방식으로 서버를 시작했다. 주소는 127.0.0.1:4173이며 외부 접속을 받지 않는다.

원본 자료를 Python Decimal로 별도 합산해 고정 기대값을 확인했다. JavaScript의 손익 함수 결과를 그대로 기대값으로 복사하지 않았다. 2026년 9월 1~18일의 비용 144행은 3,798,010원이다. 순매출 13,968,930원, 반올림 전 공헌이익 10,212,722.72원에서 실제 운영비를 빼면 손익 6,414,712.72원이며 화면에는 **6,414,713원·45.9%**다. 9월 18일 운영비는 211,000원, 손익은 278,868.32원이며 화면에는 **278,868원**이다.

## Vercel 배포 오류 수정 — 2026-10-12

사용자가 첨부한 배포 화면에서 `Forbidden`을 보고했다. `https://daeman.vercel.app/`를 읽기 전용으로 요청해 실제 HTTP 403·본문 `Forbidden`을 확인했다. 코드의 `server.mjs`는 Host가 `127.0.0.1:4173` 또는 `localhost:4173`인 경우만 허용하며, 그 외에는 같은 응답을 반환한다. Vercel에 필요한 별도 빌드 설정과 공개 출력 폴더가 없었다.

- 수정: `build.mjs`로 공개 파일 7개만 `dist`에 생성하고 `vercel.json`에 Other·빌드 명령·출력 폴더를 명시했다. 로컬 전용 서버의 주소 제한을 유지하며 배포에서는 정적 파일을 직접 제공한다. `.mjs`의 JavaScript 응답 형식과 기존 보안 헤더를 지정했다.
- 저장·계산 모듈과 데이터베이스 이름은 변경하지 않았다. 다른 접속 주소의 브라우저 기록은 자동 이전되지 않음을 README에 설명했다. 원본 data 파일은 변경하지 않았다.
- 기존 계산 검사 **53개 통과**. 배포 설정·산출물 검사 **2개 통과**, 격리된 Edge의 생성된 배포 파일 검사 **4개 통과**. [배포 검사 로그](../tests/results/deployment-browser.json).
- D01: 공개 도메인 Host 헤더로도 정적 화면 HTTP 200. D02: 모듈·초기 JSON 읽기와 9월 손익 6,414,713원 표시. D03: 실제 비용 저장 후 새로고침·JSON 내려받기. D04: 문서·원본 엑셀·서버·빌드 코드 공개 제외.
- 최초 sandbox 검사에서는 `realpath(dist)` 접근 제한으로 실패했다. 지정된 workspace/dist 절대 경로의 안전 검사를 포함한 동일 빌드를 허용된 실행 환경에서 재검사해 통과했다. 애플리케이션 오류로 해석하지 않았다.
- 위 검사는 생성된 배포 파일의 검사이며, 실제 Vercel 재배포 완료로 간주하지 않는다. EPIC 2의 U18~U23 사용자 확인 대기 상태는 유지한다.
