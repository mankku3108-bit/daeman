## 구현 범위

제공 JSON 한 번 반영, 실제 IndexedDB 저장·재접속, 일·월 조회, 메뉴·채널별 수익성, 판매 추가·수정·삭제, 저장 전 계산·재료 사용량 미리보기, 실제 수수료 입력, 하루 마감·재마감, 검색·필터·페이지 이동, 입력·저장 오류와 여러 탭 저장 충돌 처리를 구현했다.

EPIC 2·3의 비용 입력·손익·백업·재고 등록·최소 기준 설정·복원 화면은 구현하지 않았다. 제공된 비용·재고 등 원기록은 저장 상태에 보존하고, EPIC 1의 판매 재료 사용 계산과 실측 보호 로직을 검사했다. 가짜 완료 버튼이나 시안의 고정 수수료·원가를 실제 동작으로 쓰지 않았다.

### 검사 중 발견·조치

- 메뉴·채널 합계가 이전 그룹의 합계를 이어받는 오류를 발견해 각 그룹을 0부터 계산하도록 수정했다. 금액 합계와 실제 화면 검사가 통과했다.
- 검사 기대값의 포장 원가 추정값을 실제 가격이력 166.4원으로 바로잡았다.
- 12개 포장 판매의 정확한 공헌이익 41,404.8원은 화면에 41,405원으로 표시된다. 검사 기대값도 문서의 반올림 규칙에 맞췄다.
- 초기 로딩 중 마감 버튼 실행과 저장 중 입력 변경을 차단했다. 최종 브라우저 검사를 다시 실행해 통과했다.
- 여러 탭 저장 충돌 후에도 입력창 안에서 최신 자료를 읽을 수 있도록 보완했다. 비동기 읽기 완료 후 판정하도록 검사 대기 조건도 보완했다.
- 제한된 실행 환경에서 브라우저 연결이 거부되어, 승인된 로컬 실행 방식으로 서버를 시작했다. 주소는 127.0.0.1:4173이며 외부 접속을 받지 않는다.
